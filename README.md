# Swift Pink iOS Developer Guide Landing Page

A clean white and hot pink landing page for **Swift Programming Guide: Skills Required to Become an iOS Developer**. It has a centered hero with a floating CSS iPhone and glass cards, a bento skill grid, course lanes, guide cards, a sticky frosted header and a pink footer. All course and blog links are clickable.

## Run locally

No build step. Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Push `index.html` and this README to the `main` branch.
2. Go to **Settings**, then **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The page goes live at `https://YOUR-USERNAME.github.io/swift-pink-ios-developer-guide/`.

## Customise

Colours sit in the `:root` block at the top of the style section. Fonts (Sora and Nunito Sans) load from Google Fonts.
